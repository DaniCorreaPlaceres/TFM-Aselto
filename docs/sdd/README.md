# Especificaciones por tarea

Antes de implementar una tarea se crea aquí `docs/sdd/<tarea>.md`.

La ficha lleva:

- Objetivo
- Fuera de alcance
- Criterios de aceptación

La rama es `feature/<tarea>`, creada desde `develop`. El pull request vuelve a `develop`.

La memoria de producto, stack y arquitectura está en [../memoria.md](../memoria.md). Una ficha no la sustituye. Si una tarea contradice la memoria, se para y se decide antes de programar.

Al cerrar, la ficha anota solo lo comprobado.
