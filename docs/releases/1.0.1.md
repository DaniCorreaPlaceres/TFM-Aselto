# Aselto 1.0.1

Publicación solicitada el 26/11/2026; pendiente de integrar en main y verificar en Hostinger. El producto se identifica como `1.0.1` desde `app.version`, incluido el footer público. La etiqueta `v1.0.0` permanece intacta. El SHA y la etiqueta del parche se comprobarán tras la publicación.

## Corrección

El listado de Mensajes podía mostrar un error de carga y cero registros aunque las conversaciones estuviesen guardadas y sus direcciones directas funcionasen. La sección de navegación se usaba por error como filtro de la tabla. El PR #77 separa ambos valores y conserva los filtros explícitos de la bandeja, incluido el histórico personal. Evita la misma colisión en otras páginas de cliente y sus exportaciones.

No modifica mensajes, adjuntos, permisos, dependencias, contrato OpenAPI 0.6.0 ni esquema. No incorpora nuevas migraciones. Los mensajes existentes deben aparecer al cargar el listado corregido, sin necesidad de reenviarlos.

## Validación

- Corrección: 476 pruebas unitarias / 1.391 aserciones y 46 comprobaciones de integración de mensajería locales; PHPStan, plantillas y formato correctos.
- PR #77: seis checks obligatorios y paquete correctos en GitHub.
- La preparación y el PR a main ejecutarán sus comprobaciones completas. Publicar main activa el CI/CD ya autorizado: copia previa, mantenimiento, migraciones pendientes si las hubiera, esquema, caché y salud.

## Pendiente tras publicar

Verificar versión pública 1.0.1, ejecución y SHA del despliegue; recargar Mensajes como cliente y asesoría y comprobar las conversaciones existentes. Retomar el envío y descarga de adjuntos en ambos sentidos. La corrección local no acredita por sí sola el resultado productivo.
